# java-racingcar-precourse

### 기능 요구 사항

1. 입력
- [ ] 경주할 자동차 이름 입력받기 - 예시: ```pobi,woni,jun```
  - 쉼표로 분리하여 리스트화
  - [예외] 이름이 5자 초과일 경우
  - [예외] 이름에 중복된 값이 입력될 경우
  - [예외] 이름에 영어이외의 값이 들어갈 경우
  - [예외] 이름이 공백이 들어간 경우
- [ ] 시도할 횟수
  - [예외] 0 또는 음수일 경우
  - [예외] 숫자가 아닐 경우

2. 레이싱 도메인 로직
- [ ] 시도 횟수만큼 반복하며 자동차마다 무작위 값(0-9) 생성
- [ ] 값이 4이상이면 자동차 전진(위치값 + 1)
- [ ] 매 회차마다 모든 자동차에 대한 상태 값(자동차 이름, 현재 위치) 저장

3. 결과 계산 및 출력
- [ ] 입력 안내문 출력
- [ ] 시도 횟수 안내문 출력
- [ ] 실행 결과 안내문 출력
- [ ] 매 회차별 경주 상황 출력 (```이름 : ---``` 형식)
  - 저장된 값에 대해서 반복해서 '-'출력
- [ ] 모든 회차가 종료된 후 우승자 계산
  - [ ] 자동차들 중 최대 위치값 찾기
  - [ ] 최대 위치값과 동일한 자동차 이름 리스트화
- [ ] 최종 우승자 출력
  - 최종 결과 리스트 출력(쉼표로 구분)
