# **자동차 경주**

## **기능 요구 사항**

초간단 자동차 경주 게임을 구현한다.

- 경주할 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름을 5자 이하만 가능하다.
  - 예: ```pobi,woni,jun```
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.(정수만)
  - 예: ```5```
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
  - 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.
  - 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
  - 예: ```최종 우승자 : pobi, jun```
- 사용자가 잘못된 값을 입력할 경우 ```IllegalArgumentException```을 발생시킨 후 애플리케이션은 종료되어야 한다.

---

## **구현할 기능 목록**

### (1) 입력
- [x] 자동차 이름 입력
    - [ ] 쉼표(,)를 기준으로 구분

- [x] 사용자 이동 횟수 입력
  - [ ] 0 이상의 정수(0 가능)
     
### (2) 게임
- [ ] 각 자동차 전진 또는 멈춤 선택
  - [ ] 0~9 값 중 4 이상일 경우 전진 ```Randoms.pickNumberInRange(0, 9);```
     
### (3) 출력
- [x] 입력문 출력
  - [x] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"
  - [x] 자동차 이름 입력
  - [x] "시도할 횟수는 몇 회인가요?"
  - [x] 사용자 이동 횟수 입력
     
- [ ] 게임 과정 출력
  - [ ] "실행 결과"
  - [ ] 난수 결과 전진 확정 시 각 자동차에 '-' 추가

- [ ] 최종 우승자 출력
  - [ ] 단일 우승자 안내 문구
    - 예: "최종 우승자 : pobi"
  - [ ] 공동 우승자 안내 문구
    - 예: "최종 우승자 : pobi, jun"
       
### (4) 검증
- 입력 검증
  - 자동차 이름 입력
    - [ ] 같은 이름 불가능
    - [ ] 5글자 이하
    - [ ] 공백 불가능
  - 사용자 이동 횟수 입력
    - [ ] 0 이상의 정수인가
